# 🌟 ربات جامع مذهبی و قرآنی نور (NoorBot)

یک ربات کامل، مدرن، سبک، ماژولار و امن برای تلگرام، توسعه‌یافته با **Python 3.12** و فریم‌ورک **aiogram 3** بر پایه معماری Asynchronous، با پایگاه داده **PostgreSQL / Supabase** (و پشتیبانی پیش‌فرض از SQLite برای توسعه محلی)، آماده استقرار رایگان در **Render** و پایش دائمی با **UptimeRobot**.

## ✨ ویژگی‌های کلیدی ربات

### 📖 ۱. استخاره مستند با قرآن کریم
- اجرای استخاره بر پایه مصحف شریف ۶۰۴ صفحه‌ای عثمان‌طه و روش‌های اصیل شیعه.
- نمایش متن عربی با اعراب دقیق، ترجمه روان فارسی، نتیجه (بسیار خوب، خوب، میانه، نامناسب، بسیار نامناسب)، تحلیل موضوعی و راهکار عملی.
- **انتخاب مرجع تقلید:** امکان انتخاب فتوای مرجع کاربر (آیت‌الله العظمی سیستانی، آیت‌الله العظمی خامنه‌ای، آیت‌الله العظمی مکارم شیرازی).
- **انتخاب تفسیر منتخب:** تفسیر نمونه، المیزان و مجمع‌البیان.
- **اصل عدم جعل دینی:** در صورت عدم دسترسی به نگاشت معتبر یک صفحه، آیه و ترجمه با دستور به تفکر و مشورت نمایش داده شده و هرگز حکم یا نتیجه ساختگی صادر نمی‌شود.
- ثبت تاریخچه استخاره‌های کاربر، علاقه‌مندی‌ها و امکان پاکسازی تاریخچه بر مبنای حریم خصوصی.

### 🕌 ۲. مجموعهٔ مذهبی و عبادی
- **اوقات شرعی دقیق:** محاسبات نجومی استاندارد به افق تمامی مراکز استان‌ها و شهرهای زیارتی (کربلا و نجف) با روش مؤسسه ژئوفیزیک دانشگاه تهران یا مؤسسه لوای قم.
- **تسبیح‌شمار هوشمند:** شمارشگر تعاملی با دکمه‌های شیشه‌ای `(+1)`، `(-1)`، صفر کردن، نوار پیشرفت درصد و گذار خودکار بین مراحل تسبیحات حضرت زهرا (س) (۳۴ الله‌اکبر ⬅️ ۳۳ الحمدلله ⬅️ ۳۳ سبحان‌الله).
- **آیه و محتوای روز:** انتخاب آیه نورانی روز، احادیث مستند از منابع دست‌اول (نهج‌البلاغه، کافی، تحف‌العقول)، ادعیه و اذکار روزهای هفته.
- **تقویم و مناسبت‌ها:** تبدیل همزمان تاریخ به شمسی، قمری و میلادی به همراه رویدادها و اعیاد و وفیات اهل‌بیت (ع).
- **احکام و استفتائات مستند:** پاسخ به مسائل متداول شرعی با ذکر دقیق جلد و صفحه رساله مراجع تقلید.

### 👥 ۳. امکانات اختصاصی گروه‌ها
- سازگاری کامل با **Telegram Privacy Mode** و دستورات دارای `@bot_username`.
- کنترل اختصاصی پنل تنظیمات گروه برای مدیران (`/settings`).
- **حالت حریم خصوصی گروه:** امکان ارسال نتیجه استخاره به صورت امن در پی‌وی کاربر جهت حفظ راز و خلوت معنوی وی و جلوگیری از شلوغی گروه.
- فعال/غیرفعال‌سازی استخاره یا ارسال آیه روزانه در گروه.

### 🔐 ۴. پنل مدیریت و امنیت
- کنترل دسترسی مدیران با فیلتر سطح سرور (`AdminFilter`).
- آمار لحظه‌ای کاربران، گروه‌ها، تعداد استخاره‌ها، جستجوها و تسبیحات.
- **ارسال پیام همگانی (Broadcast):** با پیش‌نمایش متن، شمارش گیرندگان و **تایید صریح دو مرحله‌ای** جهت پیشگیری از ارسال اشتباهی.
- میدل‌ور ضداسپم (Rate Limiting) بر مبنای الگوریتم پنجره زمانی لغزان.
- وب‌سرور سبک در مسیر `/health` برای پایش واقعی سلامت برنامه و دیتابیس در Render.

## 🚀 راهنمای جامع راه‌اندازی و استقرار

### گام ۱: ساخت ربات در تلگرام با BotFather
1. در تلگرام وارد چت با ربات رسمی [@BotFather](https://t.me/BotFather) شوید.
2. دستور `/newbot` را ارسال کنید.
3. نام نمایشی ربات (مانند `Noor Religious Bot`) و سپس یک یوزرنیم منحصر‌به‌فرد که با `bot` خاتمه یابد (مانند `MyNoorApp_bot`) انتخاب نمایید.
4. **API Token** ارائه‌شده توسط BotFather را یادداشت کنید.
5. برای تنظیم دستورات ربات، دستور `/setcommands` را فرستاده و متن زیر را کپی کنید:
```text
start - منوی اصلی و شروع به کار ربات
istikhara - استخاره با قرآن کریم
ayah - آیه نورانی روز همراه با ترجمه
daily - تقویم و مناسبت‌های مذهبی امروز
prayer - اوقات شرعی شهر انتخابی شما
tasbih - تسبیح‌شمار هوشمند و تعاملی
quran - فهرست و جستجوی سوره‌های قرآن
settings - مدیریت تنظیمات و مرجع تقلید
help - راهنمای امکانات ربات
```

---

### گام ۲: راه‌اندازی پایگاه داده Supabase
1. به سایت [supabase.com](https://supabase.com) رفته و یک حساب رایگان ایجاد کنید.
2. دکمه **New Project** را بزنید، نامی برای پروژه (مثلاً `noorbot-db`) و یک رمز عبور قوی انتخاب کنید.
3. در منوی سمت چپ به بخش **SQL Editor** بروید.
4. تمام محتویات فایل [`sql/schema.sql`](sql/schema.sql) را در ویرایشگر کپی کرده و دکمه **Run** را بزنید تا تمام جداول، ایندکس‌ها و سیاست‌های RLS ایجاد شوند.
5. به بخش **Project Settings** ➡️ **Database** بروید و در بخش **Connection String**، زبانه **URI** (یا Connection Pooling) را انتخاب کنید. رشته اتصالی شبیه به زیر دریافت می‌کنید:
```text
postgresql://postgres.[PROJECT-REF]:[YOUR-PASSWORD]@aws-0-eu-central-1.pooler.supabase.com:6543/postgres?sslmode=require
```
*(رمز عبور خود را جایگزین `[YOUR-PASSWORD]` کنید)*.

### گام ۳: انتشار در GitHub و CI/CD
1. در سایت [GitHub](https://github.com) یک مخزن جدید با نام دلخواه بسازید.
2. در سیستم محلی خود مخزن را متصل و کامیت‌ها را ارسال نمایید:
```bash
git init
git add .
git commit -m "feat: initial commit of NoorBot"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/NoorBot.git
git push -u origin main
```
3. به محض ارسال، پایپ‌لاین **GitHub Actions** به صورت خودکار فعال شده و تمامی ۲۲ تست خودکار و یکپارچگی داده‌ها را بررسی می‌کند.

---

### گام ۴: استقرار در Render (سرویس وب)
1. وارد [render.com](https://render.com) شوید و حساب خود را با گیت‌هاب متصل کنید.
2. روی دکمه **New +** کلیک کرده و گزینه **Web Service** را انتخاب کنید.
3. مخزن GitHub ساخته‌شده را انتخاب نمایید.
4. مشخصات استقرار را به شرح زیر تنظیم کنید:
   - **Name:** `noorbot`
   - **Region:** Frankfurt (یا نزدیک‌ترین منطقه)
   - **Branch:** `main`
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python -m bot`
   - **Plan:** `Free`
5. در بخش **Advanced ➡️ Environment Variables**، متغیرهای زیر را اضافه کنید:
   - `BOT_TOKEN`: توکن دریافتی از BotFather
   - `ADMIN_IDS`: شناسه عددی اکانت تلگرام شما (از [@userinfobot](https://t.me/userinfobot) دریافت کنید)
   - `DATABASE_URL`: رشته اتصال دریافتی از Supabase
   - `ENVIRONMENT`: `production`
   - `PORT`: `8080` (رندر پورت را به طور خودکار ست می‌کند، ولی ست‌کردن آن اختیاری و استاندارد است)
6. در بخش **Health Check Path** مقدار `/health` را قرار دهید.
7. دکمه **Create Web Service** را بزنید تا برنامه ساخته و مستقر شود. پس از اتمام ساخت، آدرس دامنه وب‌سرویس شما به شکل `https://noorbot-xxxx.onrender.com` آماده است.

---

### گام ۵: تنظیم مانیتورینگ در UptimeRobot
پلن رایگان Render در صورت عدم دریافت ترافیک پس از ۱۵ دقیقه به حالت خواب (Sleep) می‌رود. برای بیدار نگه داشتن آن و ارسال پینگ دوره‌ای:
1. در سایت [uptimerobot.com](https://uptimerobot.com) ثبت‌نام کنید.
2. روی **Add New Monitor** کلیک کنید:
   - **Monitor Type:** `HTTP(s)`
   - **Friendly Name:** `NoorBot Health`
   - **URL:** `https://noorbot-xxxx.onrender.com/health` *(آدرس رندر خود را قرار دهید)*
   - **Monitoring Interval:** `Every 5 minutes` (پیش‌فرض پلن رایگان)
3. دکمه **Create Monitor** را بزنید.
> 💡 با این کار، هر ۵ دقیقه یک درخواست سبک به اندپوینت `/health` ارسال شده و علاوه بر اطمینان از سلامت سرویس و دیتابیس، از غیرفعال‌شدن کانتینر در رندر جلوگیری می‌شود.

### گام ۶: اجرای محلی (Local Development)
برای توسعه یا اجرای محلی در رایانه شخصی بدون نیاز به سرور دیتابیس:

۱. مخزن را کلون کنید و وارد پوشه شوید:
```bash
git clone https://github.com/YOUR_USERNAME/NoorBot.git
cd NoorBot
```

۲. محیط مجازی ایجاد کرده و نیازمندی‌ها را نصب کنید:
```bash
python -m venv .venv
# در ویندوز:
.\.venv\Scripts\activate
# در لینوکس / مک:
source .venv/bin/activate

pip install -r requirements.txt
```

۳. فایل `.env` را ایجاد و توکن خود را در آن وارد کنید:
```bash
# ویندوز:
copy .env.example .env
# لینوکس:
cp .env.example .env
```
*(به صورت پیش‌فرض دیتابیس محلی روی `sqlite:///noorbot.db` تنظیم است و نیازی به سرور PostgreSQL خارجی ندارید)*

۴. آماده‌سازی اولیه دیتابیس و اجرای ربات:
```bash
python scripts/seed_data.py
python -m bot
```

## 🧪 آزمون‌های خودکار و اعتبارسنجی داده‌ها

پروژه شامل یک مجموعه آزمون خودکار ۲۲ مرحله‌ای با استفاده از `pytest` و `pytest-asyncio` است. برای اجرای تست‌ها:

```bash
# اعتبارسنجی صحت داده‌های مذهبی و نگاشت‌ها
python scripts/validate_data.py

# اجرای تمامی آزمون‌های خودکار
pytest -v
```

خروجی آزمون‌ها شامل بررسی موارد زیر است:
- صحت منطق استخاره و تطابق آیات با مصحف شریف
- عدم جعل حکم در صفحات فاقد نگاشت و راهنمایی بر تدبر
- ذخیره‌سازی تاریخچه و مدیریت علاقه‌مندی‌ها
- دقت محاسبات زاویه‌ای اوقات شرعی و توالی صحیح طلوع و غروب
- صحت عملکرد میدل‌ور Throttling در مهار اسپم
- امنیت پنل ادمین و فیلترهای مجوز
- سلامت و پاسخ‌گویی مسیر `/health` سرور وب
- استفتائات فقهی مراجع تقلید

## 📚 اصالت محتوا و منابع فقهی

کلیه داده‌ها و روش‌های استخاره در ربات نور بر مبنای منابع اصیل و مستند تنظیم گردیده است:
- **احکام استخاره:** پایگاه اطلاع‌رسانی دفتر حضرت آیت‌الله العظمی سیستانی ([sistani.org](https://www.sistani.org/persian/book/26576/5988/))، پایگاه اسلام‌کوئست ([islamquest.net](https://islamquest.net/fa/archive/fa5113)) و اجوبة الاستفتائات مقام معظم رهبری.
- **متن قرآن کریم:** برگرفته از پروژه بین‌المللی [Tanzil.net](https://tanzil.net) با رسم‌الخط مصحف شریف عثمان‌طه ۶۰۴ صفحه‌ای.
- **تفاسیر قرآن:** تفسیر نمونه (آیت‌الله العظمی مکارم شیرازی)، المیزان (علامه طباطبایی)، مجمع‌البیان (شیخ طبرسی).
- **ادعیه و احادیث:** کتاب شریف نهج‌البلاغه، الکافی، مفاتیح‌الجنان و صحیفه سجادیه با ذکر دقیق جلد و صفحه.

برای مطالعه جزییات دقیق منابع و اصول عدم جعل محتوا، سند [`SOURCES.md`](SOURCES.md) را مطالعه فرمایید.
